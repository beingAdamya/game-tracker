# Pocket Library

Track your games across Steam, Xbox, PlayStation, GOG and Epic, see prices in
your currency, get sale and subscription alerts, vote in the yearly Pocket
Library Awards and share your year in games. Free, with no ads.

**Download:** [latest release](https://github.com/beingAdamya/game-tracker/releases/latest) -
Android, iPhone/iPad, Windows, Mac and Linux.

**Use it in your browser:** https://beingadamya.github.io/game-tracker/

The app updates itself when a new version is released here.

This repository only hosts the downloads and the website. The source code is
private; see [LICENSE](LICENSE).
